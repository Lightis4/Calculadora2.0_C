# Calculadora Avançada em C

## Sobre o projeto

Calculadora desenvolvida em linguagem C, com o objetivo de praticar operações matemáticas, estruturas condicionais, laços de repetição, vetores e funções da biblioteca `math.h`.

O programa funciona pelo terminal e permite realizar diversas operações sem precisar reiniciá-lo.

## Funcionalidades

- Adição, subtração, multiplicação e divisão.
- Potenciação e raiz quadrada.
- Cálculo de porcentagem.
- Resto da divisão.
- Média aritmética.
- Valor absoluto.
- Histórico dos resultados durante a execução.
- Validação de operações inválidas e divisão por zero.

## Tecnologias utilizadas

- **Linguagem:** C
- **Bibliotecas:** `stdio.h` e `math.h`
- **Compilador:** GCC
- **Editor:** Visual Studio Code

## Como executar

Clone o repositório:

```bash
git clone https://github.com/Lightis4/Calculadora2.0_C.git
```

Acesse a pasta:

```bash
cd Calculadora2.0_C
```

Compile o programa (considerando que o arquivo se chama `calculadora.c`):

```bash
gcc calculadora.c -o calculadora -lm
```

Execute no Windows:

```powershell
.\calculadora.exe
```

## Objetivo

Desenvolver conhecimentos em programação C, aplicando lógica de programação, estruturas de controle e operações matemáticas em um projeto prático.
